## Projects

### [Carleton Course Map](https://carletoncoursemap.ca/map) · [source](https://github.com/zaidahmad16/CarletonCourseMap)

Interactive degree planner used by 1,700+ students. Scrapes Carleton Central, models AND/OR prerequisite logic as a graph, and stores 3,218 courses, 304 programs and 8,882 prerequisite edges in a normalized Postgres schema, with every API query answering in under 2 ms on the server.

`Python` `FastAPI` `PostgreSQL` `Next.js` `React Flow` `dagre`

### [OntarioDriveTestMap](https://ontariodrivetestmap.fyi) · [source](https://github.com/zaidahmad16/OntarioDriveTestMap)

Free map of Ontario road test routes, which the province doesn't publish. Reconstructs 13 routes across 3 test centres from Reddit posts and dashcam video using OCR, an offline index of 19,482 OpenStreetMap junctions and HDBSCAN clustering. Every segment comes with a confidence label.

`Python` `PaddleOCR` `pyosmium` `HDBSCAN` `FastAPI` `PostgreSQL` `React` `Leaflet`

### EntityResolution.NET · starting

Python and Java have mature open-source tools for finding duplicate records. .NET doesn't. This C# library will find records that refer to the same person or company across messy data (nicknames, typos, transliterated names), scale to millions of records, and ship on NuGet.

`C#` `.NET` `ML.NET` `SQL Server` `ASP.NET Core` `Azure`

### [Nintendo DS Business Card](https://github.com/zaidahmad16/DS_Business_Card)

A business card that boots on a Nintendo DS. Play a short game and get my contact info at the end. Written in C.

`C` `NDS SDK` `ARM`

### [Ghost Hunting Simulation](https://github.com/zaidahmad16/COMP2401-Final-Project)

Multithreaded simulation in C where every actor runs on its own POSIX thread over shared memory, with zero deadlocks across 1,000+ ticks.

`C` `POSIX Threads` `Semaphores`
